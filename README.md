# 彭嘉峻 · 设计作品集

由 16 页原始 PDF 整理的响应式 HTML 作品集，包含 9 个项目、分类筛选、键盘翻页、细节放大、完整原稿在线翻阅和 PDF 下载。

## 预览

直接打开 `index.html`，或在此文件夹运行 `python3 -m http.server 8080` 后访问 `http://localhost:8080`。

## GitHub Pages

将本目录内全部文件上传到仓库根目录。前往仓库 Settings → Pages，选择 Deploy from a branch，分支 `main`，目录 `/ (root)`，保存。待部署完成后打开 GitHub 返回的网站链接。

网站使用相对路径，可部署到 GitHub Pages 的任意项目子路径。无需构建工具、账户服务或第三方 CDN。

## 维护

- `index.html`：页面文案、项目卡片、关于与联系信息。
- `style.css`：响应式样式。
- `script.js`：分类与项目阅读器，项目介绍及页码配置。
- `page-01.webp` 至 `page-16.webp`：完整 16 页原稿的网页图片。
- `peng-jiajun-portfolio.pdf`：原始 PDF，未修改。
- 其余 `.webp`：原稿裁切生成的封面、缩略图及肖像。
